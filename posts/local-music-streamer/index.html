Local music streaming on a Raspberry Pi

2026-11-22

As part of an ongoing effort to be less dependent on big-tech, I have started ripping CDs and maintaining a local mp3 library. Not only is this cheaper than Spotify (you can get used CDs under a euro), it's also a good excuse to explore new open-source software.

I wanted a streamer that plays my Navidrome library on an old Raspberry Pi 4. I had already bought a HiFiBerry DAC and set up moOde to stream to my receiver. moOde was incredibly straight-forward to set up, and worked with Navidrome using a SubSonic plugin for upmpd. The interface was the main bottleneck, and too much for anyone else in the house.

This weekend I revisited this project to look for another option that is easier to use.

The stack

This is what I ended up with:

  • piCorePlayer (pCP): the OS on the Pi. This is a very minimal OS that runs from RAM
  • Squeezelite: headless player that talks to the DAC
  • Lyrion Music Server (LMS): runs as server on pCP. It has a Web UI and is the music interface / database / queue, etc.
  • Material Skin: modern web front end for LMS
  • SqueezeSonic (xerootg fork): plugin for LMS that pulls the a Navidrome library over the Subsonic API
  • Navidrome: music source, running on my local server

pCP was just as easy to install as moOde via the Raspberry Pi Imager. The pCP web UI was a bit intimidating at first, but I quickly found my way around. The only things to do there were 1. follow the setup steps, 2. resize the filesystem (to the entire SD card) and 3. install LMS with a button.

Squeezelite auto-detected my HAT right away (sndrpihifiberry).

The LMS web UI is available on port 9000.

SqueezeSonic plugin

There are two SqueezeSonic plugins. The original (foobarjo/SqueezeSonic) is available via the Plugin manager. It works, but has an important usability issue: it hides music under My Apps. There is a hard fork (xerootg/SqueezeSonic) that imports the collection into My Music as a real library, so search, genres and album artists work. This seamlessly integrates my Navidrome library in the interface.

The repo has no releases, so I had to install the main branch:

ssh tc@pcp.home.arpa

mkdir -p /usr/local/slimserver/Cache/Plugins  # create if it does not exist
cd /usr/local/slimserver/Cache/Plugins

wget https://github.com/xerootg/SqueezeSonic/archive/refs/heads/master.zip
unzip master.zip && rm master.zip

The folder must be called exactly SqueezeSonic. The zip extracts to SqueezeSonic-master, so rename it and fix permissions:

mv SqueezeSonic-master SqueezeSonic

sudo chown -R tc:staff SqueezeSonic
sudo find SqueezeSonic -type d -exec chmod 755 {} \;
sudo find SqueezeSonic -type f -exec chmod 644 {} \;

After copying the plugin, restart LMS from pCP for the plugin to load. Enable the library under 'My Music'

/usr/local/slimserver/Cache/Plugins is symlinked to the SD card, so it does not get nuked during reboots. Two folders to avoid:

  • /usr/local/slimserver/Cache/InstalledPlugins/Plugins is managed by the plugin manager. The plugin will be overwritten by the official version on restart
  • /usr/local/slimserver/Plugins is the official manual folder, but it lives in RAM, so it does not survive a reboot.

Linking with Navidrome

In LMS, under Settings > Advanced > SqueezeSonic, set the URL for Navidrome, plus the username and password.

In Settings > Basic Settings, trigger a library rescan (this will refresh the database if it goes stale).

A full scan with a few thousand songs took a couple of minutes. After that the albums showed up under My Music, and imported playlists appear prefixed with SqueezeSonic:.

New albums in Navidrome need a rescan in LMS to appear.

Reverse proxy

In AdGuard Home I added DNS rewrites for pcp.home.arpa -> <Raspberry Pi IP> and lms.home.arpa -> <Caddy server IP>.

In Caddy (running on my main server), I set up a reverse proxy to have a nice URL for lms:

lms.home.arpa {
    reverse_proxy pcp.home.arpa:9000
}

Conclusion

The interface of LMS felt familiar right away. Material Skin on a phone looks like a normal music app, no complaints so far. It runs like a charm on a Raspberry Pi. The SqueezeSonic plugin feels a bit fragile, but so far so good.
