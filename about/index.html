About

Hi! I'm software engineer with a PhD in materials science PhD, unsatiable curiousity and infinite enthusiasm for learning new things. Combined with my passion for open-source software, this has shaped how I think about technology.

I'm a strong advocate for writing maintainable code, best practices, and user-focused design. I mostly program in Python and C#. You can find my code on Github.

After many years as a university researcher, I'm now working in a software engineer role developing open-source SDKs for automating electrochemistry measurements at PalmSens.

My favourite programming language is Python. I use Arch (btw) with the Niri scrollable-tiling window manager. I am writing this using a custom split mechanical keyboard using a self-designed keyboard layout. My text editor of choice is Zed.
